# 🎓 Pós-Graduação em Automação de Testes de Software (PGATS)
### Turma: PGATS-2026-03

Este repositório foi criado para centralizar e organizar todos os projetos prática, desafios, exercícios e códigos desenvolvidos durante as disciplinas da **Pós-Graduação em Automação de Testes de Software**.

---

## 📌 Sobre o Programa (PGATS)

A **Pós-Graduação em Automação de Testes de Software** é um programa especializado de especialização técnica (EAD 100% on-line). O curso é estruturado em **11 disciplinas** com foco aprofundado na linguagem de programação **JavaScript**, preparando os alunos para dominar as ferramentas e estratégias de automação mais requisitadas pelo mercado de tecnologia atual.

*   **Mentoria:** [Júlio de Lima](https://github.com/juliodelima)
*   **Mais informações na página oficial:** [pgats.juliodelima.com.br](https://pgats.juliodelima.com.br/)

---

## 🗂️ Estrutura de Conteúdos e Desafios

Os projetos deste repositório estão divididos de acordo com os módulos e competências avaliadas no decorrer da pós-graduação:

* **`01-Pensamento Computacional/`** Aborda as bases da resolução de problemas, decomposição, reconhecimento de padrões e pensamento abstrato aplicados ao desenvolvimento de soluções lógicas.
* **`02-Algoritmos e Lógica de Programação/`** Focado na criação de algoritmos, estruturas condicionais, laços de repetição e manipulação de dados utilizando a linguagem JavaScript.
    * *Exemplo Prático:* [Sistema de Serviço de Pagamentos com testes em Mocha & Node Assert]
* **`03-Programação para Automação de Testes/`** Domínio do ecossistema de desenvolvimento voltado para testes, abordando Programação Orientada a Objetos (POO), manipulação avançada de dados, tratamento de exceções e introdução a runners de testes automatizados.
* **`04-Integração Contínua para Automação de Testes/`** Configuração de esteiras de CI/CD (como GitHub Actions), automação de execução de testes em ambientes isolados e geração de relatórios de cobertura e execução para o time.

---

## 🛠️ Tecnologias & Ferramentas Utilizadas

Durante a jornada na PGATS, as seguintes tecnologias são aplicadas de forma prática:

*   **Linguagem Base:** JavaScript (ES6+) / Node.js
*   **Gerenciadores de Pacotes:** NPM
*   **Frameworks de Testes (Runner/Assertion):** Mocha, Node Assert
*   **Automação Web/Mobile/API:** Selenium WebDriver, Cypress, e outras ferramentas do ecossistema JS.
